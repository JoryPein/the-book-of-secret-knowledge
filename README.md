## :notebook_with_decorative_cover: &nbsp;这是什么？

这个仓库是我日常工作中使用的各种资料和工具的合集。它包含了大量实用的信息，汇集在一处。对我来说，这是一份无价的知识来源，我经常会查阅它。

## :restroom: &nbsp;为谁准备？

真的，为所有人准备。每个人都能在这里找到自己喜欢的内容。但坦白说，它主要面向系统和网络管理员、DevOps、渗透测试人员和安全研究人员。

##### :black_small_square: Shell

<p>

&nbsp;&nbsp; <a href="https://tcl-lang.org/"><b>tclsh</b></a> - 是一个非常强大的跨平台 Shell，适用于各种用途。<br>
&nbsp;&nbsp; <a href="https://github.com/Bash-it/bash-it"><b>bash-it</b></a> - 是一个用于使用、开发和维护 Shell 脚本和自定义命令的框架。<br>

###### 通过缩短 IP 地址绕过 WAF (by [0xInfection](https://twitter.com/0xInfection))

IP 地址可以通过省略零来缩短：

```
http://1.0.0.1 → http://1.1
http://127.0.0.1 → http://127.1
http://192.168.0.1 → http://192.168.1

http://0xC0A80001 或 http://3232235521 → 192.168.0.1
http://192.168.257 → 192.168.1.1
http://192.168.516 → 192.168.2.4
```

  > 这会绕过 SSRF、开放重定向等的 WAF 过滤器，这些过滤器将任何 IP 作为输入都会被列入黑名单。

更多信息请参阅 [How to Obscure Any URL](http://www.pc-help.org/obscure.htm) 和 [Magic IP Address Shortcuts](https://stuff-things.net/2014/09/25/magic-ip-address-shortcuts/)。

  printf "%s\\n" \
         "用法: ./nc-proxy 监听端口 bk_host:bk_port"
fi

_bk_host=$(echo "$2" | cut -d ":" -f1)

       "$_listen_port" "$_bk_host" "$_bk_port"

_tmp=$(mktemp -d)
_back="$_tmp/pipe.back"
_sent="$_tmp/pipe.sent"
_recv="$_tmp/pipe.recv"

trap 'rm -rf "$_tmp"' EXIT

mkfifo -m 0600 "$_back" "$_sent" "$_recv"

sed "s/^/=> /" <"$_sent" &
sed "s/^/<=  /" <"$_recv" &

nc -l -p "$_listen_port" <"$_back" | \
tee "$_sent" | \
nc "$_bk_host" "$_bk_port" | \
tee "$_recv" >"$_back"

###### 域名解析

```bash
# 依赖:
#   - curl
#   - jq

function DomainResolve() {

  local _host="$1"

  local _curl_base="curl --request GET"
  local _timeout="15"

  _host_ip=$($_curl_base -ks -m "$_timeout" "https://dns.google.com/resolve?name=${_host}&type=A" | \
  jq '.Answer[0].data' | tr -d "\"" 2>/dev/null)

  if [[ -z "$_host_ip" ]] || [[ "$_host_ip" == "null" ]] ; then

    echo -en "域名解析失败。\\n"

  else

    echo -en "$_host > $_host_ip\\n"

  fi

}
```

示例：

```bash
shell> DomainResolve nmap.org
nmap.org > 45.33.49.119

shell> DomainResolve nmap.org
域名解析失败。
```

###### 获取 ASN

```bash
# 依赖:
#   - curl

function GetASN() {

  local _ip="$1"

  local _curl_base="curl --request GET"
  local _timeout="15"

  _asn=$($_curl_base -ks -m "$_timeout" "http://ip-api.com/line/${_ip}?fields=as")

  _state=$(echo $?)

  if [[ -z "$_ip" ]] || [[ "$_ip" == "null" ]] || [[ "$_state" -ne 0 ]]; then

    echo -en "获取 ASN 失败。\\n"

  else

    echo -en "$_ip > $_asn\\n"

  fi

}
```

示例：

```bash
shell> GetASN 1.1.1.1
1.1.1.1 > AS13335 Cloudflare, Inc.

shell> GetASN 0.0.0.0
获取 ASN 失败。
```
